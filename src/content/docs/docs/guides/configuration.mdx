Stradocs does not have a dedicated configuration file. All configurations are distributed across four main files, each with distinct and separate responsibilities.

<FileTree>
  - src/ - config/ - sidebar.ts - expressive-code.ts - constants.ts -
  astro.config.mjs
</FileTree>

## `astro.config.mjs`

The main Astro configuration file. This is the first place to look when customizing Stradocs for your project.

  <Card title="site" icon="external">
    The site's production URL. This must be entered correctly so that the OG Image, RSS feed, and sitemap generate valid URLs.

    ```js
    // astro.config.mjs
    const site = 'https://your-domain.com';
    ```

  </Card>
  <Card title="title" icon="document">
    The site name that appears in the browser tab, header, and metadata. Change this to match your project name.

    ```js
    starlight({
      title: 'site name',
    })
    ```

  </Card>
  <Card title="logo" icon="star">
    The site logo in two variants—`light` and `dark`—to support light and dark modes.

    ```js
    logo: {
      light: './src/assets/logo-light.svg',
      dark: './src/assets/logo-dark.svg',
      replacesTitle: true,
    }
    ```

  </Card>
  <Card title="social" icon="github">
    Social media links that appear in the header. Add, remove, or replace them as needed.

    ```js
    social: [
      { icon: 'github', label: 'GitHub', href: 'https://github.com/username' }
    ]
    ```

  </Card>
  <Card title="locales" icon="translate">
    Language configuration. Stradocs is already configured for English `root` and Indonesian `/id`. Remove languages ​​you do not need or add new ones.

    ```js
    locales: {
      root: { label: 'English', lang: 'en' },
      id:   { label: 'Indonesia', lang: 'id' },
    }
    ```

  </Card>
  <Card title="fonts" icon="seti:font">
    The local fonts Montserrat, Inter, and FiraCode are registered here. Replace the `.woff2` files in `src/assets/fonts/` if you wish to use a different typeface.

    ```js
    fonts: [
      {
        provider: fontProviders.local(),
        name: 'Montserrat',
        cssVariable: '--font-montserrat',
        // ...
      }
    ]
    ```

  </Card>

<Aside type="caution">
  After changing `site`, rerun `npm run build` to ensure all generated URLs use
  the correct domain.
</Aside>

## `src/config/sidebar.ts`

Navigation sidebar structure configuration. All groups, labels, page order, and external links in the sidebar are managed from this file.

```ts
// src/config/sidebar.ts
export const sidebarConfig = [
  {
    label: "Getting Started",
    translations: {
      id: "Memulai",
    },
    items: [{ autogenerate: { directory: "docs/getting-started" } }],
  },
  {
    label: "Guides",
    translations: {
      id: "Panduan",
    },
    items: [{ autogenerate: { directory: "docs/guides" } }],
  },
  {
    label: "Writing",
    translations: {
      id: "Menulis",
    },
    items: [{ autogenerate: { directory: "docs/writing" } }],
  },
  {
    label: "Components",
    translations: {
      id: "Komponen",
    },
    items: [{ autogenerate: { directory: "docs/components" } }],
  },
  {
    label: "Reference",
    translations: {
      id: "Referensi",
    },
    items: [{ autogenerate: { directory: "docs/reference" } }],
  },
];
```

<Aside type="tip">
  Starlight supports various sidebar options — auto-generation, badges,
  collapsed groups, and external links. See the [Starlight
  documentation](https://starlight.astro.build/reference/configuration/#sidebar)
  for a complete reference.
</Aside>

## `src/config/expressive-code.ts`

Configure the appearance of code blocks using Expressive Code—Starlight's built-in syntax highlighting library.

```ts
// src/config/expressive-code.ts
export const expressiveCodeConfig = {
  themes: ["nama-tema"],
  // opsi lainnya...
};
```

Modify this file to change the code block theme, enable additional plugins, or customize the appearance of frames and line numbers.

## `src/constants.ts`

Constants shared across the project—a single location for values ​​used by multiple components.

```ts
// src/constants.ts
const PAGE_TITLE_ID = "_top";

export { PAGE_TITLE_ID };
...
```

<Aside>
  If there are values ​​used in more than one component—such as the site name,
  social URLs, or default author name—place them here so that changes only need
  to be made in one place.
</Aside>

## `src/styles/global.css`

The Stradocs CSS entry point. All visual customizations—colors, typography, spacing—are centralized here via CSS custom properties.

```css
/* src/styles/global.css */
:root {
  --sl-color-accent: /* warna aksen utama */;
  --sl-color-accent-high: /* warna aksen hover */;
  --font-montserrat: /* didapat otomatis dari Astro font system */;
}
```

<Aside type="tip">
  Starlight exposes all its design tokens as CSS custom properties. See the
  [Starlight CSS custom properties
  documentation](https://starlight.astro.build/reference/overrides/) for a
  complete list of variables that can be overridden.
</Aside>

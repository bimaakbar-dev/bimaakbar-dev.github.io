Stradocs is a fully redesigned [Astro Starlight](https://starlight.astro.build) theme. Not just CSS variable overrides — components, content schema, blog system, and typography are all built from the ground up around a single philosophy:

> **Clean. Premium. Modern.**

If you're already familiar with Starlight, you'll be productive right away. Stradocs doesn't change how Starlight works — it just makes it look and feel significantly better.

## What's Different from Default Starlight?

<CardGrid>
  <Card title="Component Redesign" icon="pencil">
    Header, Hero, Footer, MarkdownContent, and many other components are replaced with custom versions redesigned from scratch.
  </Card>
  <Card title="Blog System" icon="document">
    A fully integrated blog with schema extensions, RelatedPost and PopularPost components, and multi-author support.
  </Card>
  <Card title="Markdown Plugins" icon="setting">
    `satteriExternalLink` and `satteriTable` plugins are active automatically across all content — no manual imports needed.
  </Card>
  <Card title="Local Fonts" icon="seti:font">
    Montserrat, Inter, and FiraCode are self-hosted via `fontProviders.local()` — no external CDN requests.
  </Card>
  <Card title="OG Image & RSS" icon="external">
    Every page generates an Open Graph image automatically. RSS feed available at `/rss.xml`.
  </Card>
  <Card title="Bilingual" icon="translate">
    Configured for English and Indonesian out of the box, including i18n strings for all blog components.
  </Card>
</CardGrid>

## Relationship with Starlight

Stradocs is Starlight — not a fork, not a wrapper. Everything you know about Starlight still applies here: content structure, routing, sidebar, i18n, and configuration all work exactly the same.

<Aside type="tip">
  The official Starlight documentation remains your primary reference. Stradocs only adds and replaces the visual layer on top of it.
</Aside>

The difference is that components are already replaced, plugins are already active, and the blog system is already ready to use — so you don't need to build any of that from scratch.

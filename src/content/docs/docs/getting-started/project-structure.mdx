Stradocs follows the standard Astro + Starlight project structure with several additional directories for the blog system, plugins, and custom styling. This page explains the role of each folder and key file.

<Aside type="tip">
  If you're already familiar with Astro or Starlight project structure, most
  folders here will feel familiar. Focus on the directories that **don't exist**
  in default Starlight: `lib/`, `styles/components/`, and the extended
  `content/` structure.
</Aside>

### Root

| File                | Description                                                                                           |
| ------------------- | ----------------------------------------------------------------------------------------------------- |
| `astro.config.mjs`  | Main Astro configuration — fonts, Starlight integration, Tailwind, Satteri plugins, and site settings |
| `content.config.ts` | Collection definitions for docs and i18n, including blog schema extensions                            |
| `tsconfig.json`     | TypeScript configuration                                                                              |
| `CLAUDE.md`         | Project context for Claude — architecture notes and guidelines                                        |
| `AGENTS.md`         | Project context for other AI agents                                                                   |

### `public/`

Static assets served directly without Astro processing.

| Path                        | Description                   |
| --------------------------- | ----------------------------- |
| `public/images/favicon.svg` | Site favicon                  |
| `public/robots.txt`         | Instructions for web crawlers |

### `src/assets/`

Assets processed by Astro — optimized, hashed, and bundled at build time.

<CardGrid>
  <Card title="fonts/" icon="seti:font">

    registered from here via `astro.config.mjs`.
  </Card>
  <Card title="images/blog/" icon="document">
    Hero images for blog posts. Referenced from the `heroImage` frontmatter

  </Card>
  <Card title="images/author/" icon="pencil">

  <Card title="images/hero/" icon="star">

    pages.
  </Card>

### `src/components/`

Contains two types of components:

1. **Starlight component overrides** — components with the same name as Starlight's built-ins, registered in `astro.config.mjs` under the `components` key. These fully replace Starlight's default rendering.
2. **Custom Stradocs components** — additional components not present in default Starlight, such as `RelatedPost`, `PopularPost`, and other blog-specific components.

<Aside>
  The full list of overridden components can be found in `astro.config.mjs` under `components: { ... }`.
</Aside>

### `src/config/`

Configuration split out from `astro.config.mjs` for easier maintenance.

| File                 | Description                                                                         |
| -------------------- | ----------------------------------------------------------------------------------- |
| `expressive-code.ts` | Expressive Code configuration override — code block appearance, themes, and plugins |
| `sidebar.ts`         | Sidebar navigation configuration — group structure, labels, and page ordering       |

### `src/content/`

All site content. Stradocs extends Starlight's content structure with a `blog/` folder and a separate i18n structure.

<FileTree>
  - content/ 
    - docs/
      - docs/
        - **English documentation content (route `/docs/`)** 
      - blog/
        - **English blog posts (route `/blog/`)** 
      - id/ 
        - docs/
          - **Indonesian documentation content (route `/id/docs/`)** 
        - blog/ 
          - **Indonesian blog posts (route `/id/blog/`)** 
        - index.astro 
      - index.astro 
      - i18n 
        - en.json 
        - id.json 
      - 404.md
</FileTree>

<Aside type="tip">
  Markdown and MDX files in `docs/` are managed automatically by Starlight.
  Files in `blog/` are handled by the custom pages in `src/pages/blog/`.
</Aside>

### `src/lib/`

Internal utilities and plugins for Stradocs.

<FileTree>
  - lib/ 
    - plugins/ 
      - satteri/ 
        - **`satteriExternalLink`** # hast plugin for external links 
        - **`satteriTable`** # hast plugin for responsive tables
</FileTree>

These plugins are registered in `astro.config.mjs` under `markdown.processor` and are active automatically across all content.

### `src/pages/`

Custom pages not managed by Starlight - specifically for the blog system.

<FileTree>
  - pages/ 
    - blog/ 
      - index.astro # English blog listing page 
      - [...slug].astro # English blog post detail page 
    - id/ 
      - blog/ 
        - index.astro # Indonesian bloglisting page 
        - [...slug].astro # Indonesian blog post detail page 
      - rss.xml.js # Indonesian RSS feed 
    - rss.xml.js # English RSS feed
</FileTree>

<Aside>
  All pages outside `blog/` are managed automatically by Starlight based on
  files in `src/content/docs/`.
</Aside>

### `src/styles/`

Stradocs' styling system is organized to follow Starlight's CSS layer structure.

| File / Folder          | Description                                                                |
| ---------------------- | -------------------------------------------------------------------------- |
| `components/`          | CSS overrides for Starlight components in the `@layer components` layer    |
| `components-internal/` | CSS overrides for Starlight's internal components                          |
| `user-components/`     | CSS overrides for Starlight's user-facing components                       |
| `asides.css`           | Override styles for Starlight's built-in `<Aside>` component               |
| `global.css`           | Main entry point — imports all CSS files and defines custom CSS properties |
| `markdown.css`         | Override for Markdown content typography and styling                       |
| `reset.css`            | Override for Starlight's CSS reset                                         |
| `stradocs.css`         | Additional custom CSS outside of Starlight override categories             |

<Aside type="tip">
  `global.css` is the only file registered in `astro.config.mjs` under
  `customCss`. All other files are imported from here.
</Aside>

### `src/constants.ts`

Contains constants used across the project — site name, URLs, default configuration, and shared values used between components.

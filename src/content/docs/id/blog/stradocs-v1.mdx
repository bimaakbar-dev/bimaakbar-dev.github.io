[Astro Starlight](https://starlight.astro.build) adalah fondasi dokumentasi yang solid — ringan, berbasis MDX, dan terstruktur dengan baik. Tapi tampilannya yang default terasa generik. Untuk proyek yang ingin punya identitas visual sendiri, itu jadi hambatan sejak hari pertama.

Terinspirasi oleh pendekatan desain **Fumadocs** yang bersih dan teropini, serta estetika sistem **Vercel** yang presisi dan minimal, Stradocs dibangun di atas satu filosofi:

> **Clean. Premium. Modern.**

Bukan starter kit asal jadi — melainkan tema yang sudah memikirkan tipografi, komponen, skema konten, dan pengalaman menulis sejak awal. Setiap detail dirancang agar hasilnya terasa selesai, bukan setengah jadi.

### Markdown Plugins

<Aside type="note">
  Astro 7 menggunakan `@astrojs/markdown-satteri` sebagai markdown processor default — pipeline berbasis Rust yang jauh lebih cepat dari remark/rehype.
</Aside>

Stradocs menambahkan dua plugin custom berbasis hast yang bekerja di level AST:

<CardGrid>
  <Card title="satteriExternalLink" icon="external">
    Memproses semua tautan eksternal secara otomatis. Setiap tautan keluar dari situs mendapat atribut dan indikator visual yang tepat — tanpa penulis perlu menulis markup tambahan.
  </Card>
  <Card title="satteriTable" icon="list-format">
    Membungkus setiap tabel dalam container responsif yang scrollable horizontal. Berlaku otomatis untuk semua konten Markdown dan MDX, termasuk konten yang sudah ada.
  </Card>
</CardGrid>

<Aside type="tip">
  Karena kedua plugin bekerja di level hast AST, fiturnya aktif di **seluruh file Markdown dan MDX** tanpa perlu import komponen tambahan di setiap file konten.
</Aside>

### Extended Schema untuk Blog

Skema konten Starlight diperluas menggunakan opsi `extend` dari `docsSchema()`. Semua field bersifat opsional — halaman dokumentasi biasa tidak perlu menyertakannya.

```ts
// src/content/config.ts
schema: docsSchema({
  extend: ({ image }) => z.object({
    pubDate: z.coerce.date().optional(),
    heroImage: z.optional(image()),
    author: z.array(z.object({
      name: z.string().optional(),
      avatar: z.optional(image()),
    })).optional(),
    tags: z.array(z.string()).optional(),
  }),
})
```

Contoh frontmatter artikel blog:

```yaml
---
title: 'Judul Artikel'
description: 'Deskripsi singkat.'
pubDate: 2025-09-01
author:
  - name: 'Bima Akbar'
    avatar: ~/assets/images/author/bimaakbar-dev.svg
heroImage: ~/assets/images/blog/cover.jpg
tags:
  - astro
  - tutorial
draft: false
---
```

| Field | Tipe | Keterangan |
|---|---|---|
| `pubDate` | `Date` (opsional) | Tanggal publikasi; di-coerce otomatis dari string |
| `heroImage` | `ImageMetadata` (opsional) | Gambar utama, diproses Astro Image |
| `author` | `{ name?, avatar? }[]` (opsional) | Array penulis — mendukung multi-author dengan avatar |
| `tags` | `string[]` (opsional) | Kategori / tag artikel |

<Aside type="tip">
  `author` didesain sebagai **array** — satu artikel bisa memiliki lebih dari satu penulis, masing-masing dengan nama dan avatar sendiri.
</Aside>

### Dukungan Dua Bahasa

Stradocs dikonfigurasi bilingual sejak awal: **English** sebagai root dan **Indonesia** di `/id`.

Selain routing i18n bawaan Starlight, string UI komponen blog juga bisa diterjemahkan penuh melalui i18n schema extension:

```ts
schema: i18nSchema({
  extend: z.object({
    'blog.PostAuthor': z.string().optional(),
    'blog.relatedPostLabel': z.string().optional(),
    'blog.PopularPostLabel': z.string().optional(),
    'rss.RssFeedLabel': z.string().optional(),
    'rss.RssFeedTitle': z.string().optional(),
    'rss.RssFeedDesc': z.string().optional(),
  }),
})
```

Tidak ada string yang di-hardcode di dalam komponen — semuanya bisa diterjemahkan.

## Open Source

Stradocs dibangun oleh **Bima Akbar** dan dirilis sepenuhnya **gratis dan open source**. Tidak ada lisensi berbayar, tidak ada fitur yang dikunci. Kontribusi dalam bentuk apapun sangat terbuka — bug report, pull request, saran fitur, atau sekadar diskusi.

```bash
# Clone repositori
git clone https://github.com/bimaakbar-dev/bimaakbar-dev.github.io.git my-docs

cd my-docs
npm install
npm run dev
```

</Aside>

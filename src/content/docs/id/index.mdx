## Apa itu Stradocs?

Stradocs adalah kumpulan model dan varian desain untuk komponen-komponen di Starlight.

Starlight sendiri sudah menyediakan fitur yang sangat baik untuk meng-override komponen melalui konfigurasi `components`. Daftar lengkap komponen yang bisa di-override dapat Anda lihat di dokumentasi resmi Starlight.

Secara default, Starlight menyediakan satu model untuk setiap komponen. Stradocs hadir untuk memberikan Anda lebih banyak pilihan model dari komponen yang sama.

## Apa yang Kami Sediakan?

### 1. Varian untuk Component Overrides

Untuk setiap komponen yang terdaftar di reference resmi Starlight, kami menyediakan beberapa variasi model.

Setiap varian tetap mengikuti struktur dari source asli Starlight, namun dengan penambahan elemen atau penyesuaian layout agar lebih fleksibel untuk kebutuhan yang berbeda.

### 2. Trik untuk Komponen di Luar Reference

Tidak semua bagian antarmuka bisa di-override melalui `components`. Untuk bagian tersebut, kami akan membagikan trik melalui CSS dan menjelaskan komponen apa saja yang perlu disesuaikan agar trik tersebut dapat bekerja.

## Tujuan Project Ini

Tujuannya sederhana: membantu Anda membuat dokumentasi Starlight yang lebih personal dan memiliki karakter sendiri, tanpa harus memulai dari nol.

Anda tidak perlu membongkar source code satu per satu. Cukup lihat katalog, pilih model yang Anda suka, dan gunakan di project Anda.

## Open Source

Project ini bersifat open source dan terbuka untuk kontribusi. Jika Anda memiliki ide model baru atau trik yang berguna, Anda dapat berkontribusi melalui GitHub.

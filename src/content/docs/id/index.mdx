## Cara Kerja

Stradocs adalah Starlight — bukan fork, bukan wrapper. Semua yang kamu tahu tentang Starlight tetap berlaku. Stradocs hanya menambahkan dan mengganti lapisan visual di atasnya.

<CardGrid>
  <Card title="1. Clone" icon="github">
    Fork atau clone repositori Stradocs dari GitHub. Tidak ada package global yang perlu diinstall.

    ```bash
    git clone https://github.com/bimaakbar-dev/bimaakbar-dev.github.io.git
    ```
  </Card>
  <Card title="2. Kustomisasi" icon="setting">
    Sesuaikan `astro.config.mjs`, sidebar, font, dan konten. Arsitektur Stradocs dirancang mudah dibaca dan dimodifikasi.
  </Card>
  <Card title="3. Deploy" icon="rocket">
    Build dan deploy ke GitHub Pages atau platform pilihan kamu. Stradocs sudah dikonfigurasi untuk GitHub Pages sejak awal.
  </Card>
</CardGrid>

## FAQ

<Card title="Apakah Stradocs menggantikan Starlight?" icon="information">
  Tidak. Stradocs adalah Starlight yang dikustomisasi — semua fitur, routing, dan konfigurasi Starlight tetap berfungsi normal. Stradocs hanya mengganti lapisan visual dan menambahkan sistem blog.
</Card>

<Card title="Apakah saya perlu tahu Astro untuk menggunakannya?" icon="information">
  Ya. Stradocs ditujukan untuk pengguna yang sudah familiar dengan Astro dan Starlight. Jika baru memulai, pelajari keduanya terlebih dahulu sebelum menggunakan Stradocs.
</Card>

<Card title="Apakah Stradocs gratis?" icon="information">
  Ya, sepenuhnya gratis dan open source. Fork repositori dan gunakan untuk proyek apapun tanpa biaya.
</Card>

<Card title="Bisakah saya berkontribusi?" icon="information">
  Tentu. Kontribusi dalam bentuk apapun sangat terbuka — bug report, pull request, saran fitur, atau sekadar diskusi di repositori GitHub.
</Card>

<Card title="Apakah Stradocs mendukung multi-bahasa?" icon="information">
  Ya. Stradocs dikonfigurasi untuk English dan Indonesia sejak awal. Bahasa tambahan bisa ditambahkan melalui konfigurasi `locales` di `astro.config.mjs`.
</Card>

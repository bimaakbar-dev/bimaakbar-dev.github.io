Komponen **Asides** di Stradocs menggunakan cara penulisan **Github**, bisa digunakan dalam **MDX** dan **Markdown** dengan simbol `> [!variant]`.  

import { PreviewPanel } from '~/stradocs/components';

<Fragment slot='preview'>

> [!NOTE]
> Ini adalah aside  

</Fragment>

</PreviewPanel>  

## Penggunaan

<PreviewPanel>

```mdx
> [!NOTE]
> Ini adalah Aside  
> Lorem ipsum dolor sit amet.
```

<Fragment slot='preview'>

> [!NOTE]
> Ini adalah Aside  
> Lorem ipsum dolor sit amet.

</Fragment>

</PreviewPanel>  

## Props  
Komponen ini mempunyai beberapa jenis `variant`:

`[!variant]`
: **required**  

  **variant:** `[!NOTE] | [!TIP] | [!WARNING] | [!DANGER]`  
  
  Setiap variant harus menggunakan huruf kapital.

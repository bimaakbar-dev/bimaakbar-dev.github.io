## Key Features

<CardGrid bento>
  <Card title="Redesigned Components" icon="pencil">
    The Header, Hero, Footer, and many other Starlight components have been
    replaced with visually redesigned versions—going beyond simple color
    changes.
  </Card>
  <Card title="Integrated Blog System" icon="document">
    A full-featured blog system including schema extensions, multi-author
    support, Related Posts, Popular Posts, and RSS feeds—ready to use out of the
    box.
  </Card>
  <Card title="Automatic Markdown Plugins" icon="setting">
    The `satteriExternalLink` and `satteriTable` plugins are automatically
    enabled across all content—no manual imports required in individual files.
  </Card>
  <Card title="Local Fonts" icon="seti:font">
    Montserrat, Inter, and FiraCode are hosted locally—eliminating external CDN
    requests to ensure optimal performance and privacy.
  </Card>
  <Card title="Automatic OG Images" icon="external">
    Every page automatically generates an Open Graph image, ensuring a
    consistent appearance when shared on social media.
  </Card>
  <Card title="Bilingual Support" icon="translate">
    Pre-configured for English and Indonesian, including i18n strings for all
    blog components.
  </Card>
</CardGrid>

## How It Works

Stradocs is Starlight—not a fork, not a wrapper. Everything you know about Starlight still applies. Stradocs simply adds and replaces the visual layer on top.

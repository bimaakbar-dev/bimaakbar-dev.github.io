Stradocs adalah tema [Astro Starlight](https://starlight.astro.build) yang didesain ulang secara menyeluruh. Bukan sekadar override variabel CSS — komponen, skema konten, sistem blog, dan tipografi semuanya dirancang dari awal dengan satu filosofi:

<Testimonial
  name="Bima Akbar"
  handle="bimaakbar"
  cite="https://twitter.com/astrodotbuild/status/1724934718745915558"
>
  Bersih. Premium. Modern.
</Testimonial>

Jika kamu sudah familiar dengan Starlight, kamu langsung bisa produktif. Stradocs tidak mengubah cara kerja Starlight — ia hanya membuatnya terlihat dan terasa jauh lebih baik.

---

## Apa yang Berbeda dari Starlight Default?

<CardGrid>
  <Card title="Redesign Komponen" icon="pencil">
    Header, Hero, Footer, MarkdownContent, dan banyak komponen lain diganti dengan versi custom yang didesain ulang secara visual.
  </Card>
  <Card title="Sistem Blog" icon="document">
    Halaman blog terintegrasi penuh dengan schema extension, komponen RelatedPost dan PopularPost, serta dukungan multi-author.
  </Card>
  <Card title="Markdown Plugins" icon="setting">
    Plugin `satteriExternalLink` dan `satteriTable` aktif otomatis di seluruh konten — tanpa import tambahan.
  </Card>
  <Card title="Font Lokal" icon="seti:font">
    Montserrat, Inter, dan FiraCode dihosting lokal via `fontProviders.local()` — tanpa request ke CDN eksternal.
  </Card>
  <Card title="OG Image & RSS" icon="external">
    Setiap halaman menghasilkan Open Graph image otomatis. Feed RSS tersedia di `/rss.xml`.
  </Card>
  <Card title="Bilingual" icon="translate">
    Dikonfigurasi untuk English dan Indonesia sejak awal, termasuk i18n string untuk komponen blog.
  </Card>
</CardGrid>

## Hubungan dengan Starlight

Stradocs adalah Starlight — bukan fork, bukan wrapper. Semua yang kamu tahu tentang Starlight tetap berlaku di sini: struktur konten, routing, sidebar, i18n, dan konfigurasi bekerja persis sama.

<Aside type="tip">
  Dokumentasi resmi Starlight tetap menjadi referensi utama. Stradocs hanya menambahkan dan mengganti lapisan visual di atasnya.
</Aside>

Yang membedakan hanyalah komponen yang sudah diganti, plugin yang sudah aktif, dan sistem blog yang sudah siap pakai — sehingga kamu tidak perlu menyentuh hal-hal itu dari nol.

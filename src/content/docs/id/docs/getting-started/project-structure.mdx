Stradocs mengikuti struktur standar proyek Astro + Starlight dengan beberapa direktori tambahan untuk kebutuhan blog, plugin, dan sistem styling custom. Halaman ini menjelaskan peran setiap folder dan file penting.

<Aside type="tip">
  Jika kamu sudah familiar dengan struktur proyek Astro atau Starlight, sebagian besar folder di sini akan terasa familiar. Fokus pada direktori yang **tidak ada** di Starlight default: `lib/`, `styles/components/`, dan struktur `content/` yang diperluas.
</Aside>

### Root

| File | Keterangan |
|---|---|
| `astro.config.mjs` | Konfigurasi utama Astro — font, integrasi Starlight, Tailwind, plugin Satteri, dan konfigurasi site |
| `content.config.ts` | Definisi collection docs dan i18n beserta schema extension untuk blog |
| `tsconfig.json` | Konfigurasi TypeScript |
| `CLAUDE.md` | Konteks proyek untuk Claude — panduan dan catatan arsitektur |
| `AGENTS.md` | Konteks proyek untuk AI agent lainnya |

### `public/`

Aset statis yang disajikan langsung tanpa diproses Astro.

| Path | Keterangan |
|---|---|
| `public/images/favicon.svg` | Favicon situs |
| `public/robots.txt` | Instruksi untuk web crawler |

### `src/components/`

Berisi dua jenis komponen:

1. **Override komponen Starlight** — komponen dengan nama yang sama dengan bawaan Starlight, didaftarkan di `astro.config.mjs` pada key `components`. Komponen ini menggantikan rendering bawaan Starlight sepenuhnya.
2. **Komponen custom Stradocs** — komponen tambahan yang tidak ada di Starlight default, seperti `RelatedPost`, `PopularPost`, dan komponen blog lainnya.

<Aside>
  Daftar komponen yang di-override dapat dilihat di `astro.config.mjs` pada bagian `components: { ... }`.
</Aside>

### `src/config/`

Konfigurasi yang dipisah dari `astro.config.mjs` agar lebih mudah dikelola.

| File | Keterangan |
|---|---|
| `expressive-code.ts` | Override konfigurasi Expressive Code — tampilan blok kode, tema, dan plugin |
| `sidebar.ts` | Konfigurasi sidebar navigasi — struktur grup, label, dan urutan halaman |

### `src/content/`

Seluruh konten situs. Stradocs memperluas struktur konten Starlight dengan folder `blog/` dan struktur i18n tersendiri.

<FileTree>
- content/
  - docs/
    - **Konten dokumentasi English (rute `/docs/`)**
  - blog/
    - **Artikel blog English (rute `/blog/`)**
  - id/
    - docs/
      - **Konten dokumentasi Indonesia (rute `/id/docs/`)**
    - blog/
      - **Artikel blog Indonesia (rute `/id/blog/`)**
  - index.astro
  - i18n/
    - en.json
    - id.json
  - 404.md
</FileTree>

<Aside type="tip">
  File Markdown dan MDX di `docs/` dikelola Starlight secara otomatis. File di `blog/` dikelola oleh halaman custom di `src/pages/blog/`.
</Aside>

### `src/lib/`

Utilitas dan plugin internal Stradocs.

<FileTree>
- lib/
  - plugins/
    - satteri/
      - **`satteriExternalLink`** — plugin hast untuk tautan eksternal
      - **`satteriTable`** — plugin hast untuk tabel responsif
</FileTree>

Plugin-plugin ini didaftarkan di `astro.config.mjs` pada bagian `markdown.processor` dan aktif otomatis di seluruh konten.

### `src/pages/`

Halaman custom yang tidak dikelola Starlight — khususnya untuk sistem blog.

<FileTree>
- pages/
  - blog/
    - index.astro        # Halaman listing blog English
    - [...slug].astro    # Halaman detail artikel blog English
  - id/
    - blog/
      - index.astro      # Halaman listing blog Indonesia
      - [...slug].astro  # Halaman detail artikel blog Indonesia

</FileTree>

<Aside>
  Semua halaman di luar `blog/` dikelola otomatis oleh Starlight berdasarkan file di `src/content/docs/`.
</Aside>

### `src/styles/`

Sistem styling Stradocs diorganisir mengikuti struktur lapisan CSS Starlight.

| File / Folder | Keterangan |
|---|---|
| `components/` | Override CSS untuk komponen Starlight yang berada di layer `@layer components` |
| `components-internal/` | Override CSS untuk komponen internal Starlight |
| `user-components/` | Override CSS untuk user-facing components Starlight |
| `asides.css` | Override styling komponen `<Aside>` bawaan Starlight |
| `global.css` | Entry point utama — mengimpor semua file CSS dan mendefinisikan CSS custom properties |
| `markdown.css` | Override tipografi dan styling konten Markdown |
| `reset.css` | Override CSS reset bawaan Starlight |
| `stradocs.css` | CSS custom tambahan yang tidak termasuk dalam kategori override Starlight |

<Aside type="tip">
  `global.css` adalah satu-satunya file yang didaftarkan di `astro.config.mjs` pada `customCss`. Semua file lain diimpor dari sini.
</Aside>

### `src/constants.ts`

Berisi konstanta yang digunakan di seluruh proyek — nama situs, URL, konfigurasi default, dan nilai-nilai yang dipakai bersama antar komponen.

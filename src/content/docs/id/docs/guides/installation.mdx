Stradocs didistribusikan sebagai repositori GitHub yang bisa langsung di-fork atau di-clone. Tidak ada package yang perlu diinstall secara global — cukup clone, install dependencies, dan langsung jalan.

<Aside type="tip">
  Stradocs dibangun di atas Astro dan Starlight. Pastikan kamu sudah familiar
  dengan keduanya sebelum melanjutkan.
</Aside>

## Requirements

| Requirement | Versi Minimum             |
| ----------- | ------------------------- |
| Node.js     | `18.20.8` atau lebih baru |
| Git         | Versi terbaru             |

## Clone Repositori

<Steps>

1. **Fork atau clone repositori Stradocs**

   Fork melalui GitHub jika ingin menyimpan perubahan ke repositori kamu sendiri, atau clone langsung jika hanya ingin eksplorasi lokal.

   ```bash
   git clone https://github.com/bimaakbar-dev/bimaakbar-dev.github.io.git my-docs
   ```

2. **Masuk ke direktori proyek**

   ```bash
   cd my-docs
   ```

3. **Install dependencies**

   <Tabs>
     <TabItem label="npm" icon="seti:npm">
       ```bash npm install ```
     </TabItem>
     <TabItem label="pnpm" icon="pnpm">
       ```bash pnpm install ```
     </TabItem>
     <TabItem label="yarn" icon="seti:yarn">
       ```bash yarn install ```
     </TabItem>
   </Tabs>

4. **Jalankan development server**

   <Tabs>
     <TabItem label="npm" icon="seti:npm">
       ```bash npm run dev ```
     </TabItem>
     <TabItem label="pnpm" icon="pnpm">
       ```bash pnpm dev ```
     </TabItem>
     <TabItem label="yarn" icon="seti:yarn">
       ```bash yarn dev ```
     </TabItem>
   </Tabs>

   Buka [http://localhost:4321](http://localhost:4321) di browser. Stradocs siap digunakan.

</Steps>

## Scripts yang Tersedia

| Script            | Keterangan                                                           |
| ----------------- | -------------------------------------------------------------------- |
| `npm run dev`     | Menjalankan development server di `localhost:4321` dengan hot reload |
| `npm run build`   | Build untuk production ke folder `dist/`                             |
| `npm run preview` | Preview hasil build secara lokal sebelum deploy                      |

## Build untuk Production

Saat siap deploy, jalankan build command:

<Tabs>
  <TabItem label="npm" icon="seti:npm">
    ```bash npm run build ```
  </TabItem>
  <TabItem label="pnpm" icon="pnpm">
    ```bash pnpm build ```
  </TabItem>
  <TabItem label="yarn" icon="seti:yarn">
    ```bash yarn build ```
  </TabItem>
</Tabs>

Output build akan berada di folder `dist/`. Stradocs dikonfigurasi untuk deploy ke **GitHub Pages** — konfigurasi `site` di `astro.config.mjs` sudah diset ke URL repositori.

<Aside>
  Jika ingin deploy ke platform lain, sesuaikan nilai `site` dan `base` di
  `astro.config.mjs` mengikuti dokumentasi Astro untuk platform yang dituju.
</Aside>

Selamat datang di **Stradocs V1.0**—rilis perdana dari tema kustom Starlight yang dibangun khusus untuk menghadirkan pengalaman dokumentasi dan publikasi yang bersih, cepat, serta sepenuhnya independen dari layout bawaan.

## Filosofi

Dalam pengembangan tema ini, fokus utama kami adalah kebebasan tata letak (*layout freedom*). Dengan menanggalkan sidebar bawaan Starlight dan mengoptimalkan struktur halaman kustom via `Page.astro`, tema ini memberikan ruang baca yang luas tanpa distraksi elemen UI yang tidak diperlukan.

## Fitur Utama Tema Stradocs V1.0

- **Custom Page Architecture:** Pengendalian penuh terhadap elemen kerangka HTML dan struktur dokumen secara langsung.
- **Optimized Styling:** Memanfaatkan penyematan CSS modular untuk menjaga performa render tetap ringan.
- **Automated Syndication:** Dukungan *RSS Feed* bawaan untuk memudahkan pembaca melacak artikel terbaru.
